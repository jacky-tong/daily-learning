# Daily Learning

每天学懂一个小知识点，并留下可以运行、可以复习、可以验证的成果。

这个仓库有两个目标：

1. 用真实学习成果维持稳定的 GitHub 贡献记录；
2. 每周从学习内容中挑选适合的问题，尝试做一次高质量开源贡献。

## 每日流程

对 Codex 说：`开始今日 GitHub`。

随后会依次完成：

1. 检查今天是否已有学习记录；
2. 从 [学习路线](ROADMAP.md) 选择一个不重复的小主题；
3. 生成一篇短笔记、一个最小实验和几个自测题；
4. 运行仓库内的自动检查；
5. 将通过检查的内容提交到 `main`；
6. 返回提交链接，并用几句话讲清楚今天学到了什么。

默认通过 GitHub 接口更新，不下载整个仓库。确实需要运行外部项目时，采用浅层、稀疏的临时副本，任务完成后清理。

## 仓库结构

```text
daily/       每日学习笔记
labs/        与笔记配套的最小实验
scripts/     内容与代码校验
templates/   每日笔记模板
```

## 原则

- 不创建空提交，不复制无来源内容；
- 每次提交都应留下一个可以解释的知识点；
- 不为追求绿格子向外部项目发送低质量 Issue 或 PR；
- 自动化负责减少重复劳动，学习和判断仍由人完成。
